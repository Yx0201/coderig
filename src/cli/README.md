# CLI 模块

CLI 模块提供交互式终端聊天界面，负责用户输入接收、LLM 流式响应渲染、工具调用编排等核心交互逻辑。

## 文件说明

### chat.ts

主聊天循环，核心功能包括：

- **对话管理** — 支持新建对话和续话（通过 `resumeCid` 恢复历史对话）
- **流式渲染** — 实时展示 LLM 的推理过程（灰色 dim 文字）和最终回答，自动处理思考→回答的换行分隔
- **工具调用编排** — 根据工具定义将只读工具并行执行、写工具串行执行，避免数据竞争
- **权限门** — 调用工具前按 `auto`/`ask`/`deny` 三级权限检查，支持会话级免确认
- **空回答兜底 (Nudge)** — 模型连续多次只推理不回答时，自动注入提示消息促其产出
- **上下文压缩** — 超出 token 预算时自动调用模型生成摘要压缩历史，支持截断兜底
- **观测与追踪** — 集成 `Tracer`，记录每次 LLM 请求、工具调用、权限决策、压缩等事件

### render.ts

终端渲染工具函数：

| 函数 | 用途 |
|---|---|
| `renderInfo(msg)` | 灰色信息输出 |
| `renderWarning(msg)` | 黄色警告输出 |
| `renderError(msg)` | 红色错误输出 |
| `renderSuccess(msg)` | 绿色成功输出 |
| `renderLoading()` | 返回 `{ start, stop }` 控制加载旋转动画 |
